## What is in this repo

- `main.py` — the program. Run with Python 3.13 and Pillow (`pip install pillow`).
  It draws a one-page newspaper front page with the 9 biggest stories of
  19 November 2026 and writes it to `/output/entry.png` — 960x640 PNG,
  about 74 KB (limit: max 1024x1024, max 1 MB). Deterministic, no network,
  no input files. Run it twice and it writes identical bytes.
- `LICENSE` — MIT, copyright 2026 Andre Setiawan.
- `.makefun/owner.json` — payout wallet for the entry owner.
